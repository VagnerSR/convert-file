Converta HTML em PDF com um clique

⬇ Baixar html_to_pdf.bat

Para Windows 10 e 11 · Arquivo pequeno · Sem instalação

Como usar

  1. Baixe o arquivo html_to_pdf.bat no botão acima.
  2. Copie-o para a mesma pasta onde estão os arquivos HTML.
  3. Dê dois cliques no arquivo html_to_pdf.bat.
  4. Aguarde a conversão. Os PDFs aparecerão na pasta pdfs, criada automaticamente, com o mesmo nome dos originais.

Bom saber

  • Converte todos os arquivos .html e .htm da pasta.
  • Usa o Microsoft Edge (já incluído no Windows) ou o Google Chrome. Nada precisa ser instalado.
  • Se já existir um PDF com o mesmo nome na pasta pdfs, o novo arquivo é salvo como nome (1).pdf, nome (2).pdf e assim por diante. Nenhum PDF anterior é substituído.
  • Imagens e estilos que estejam em arquivos separados continuam funcionando se permanecerem ao lado do HTML.
  • Nomes de arquivo com ponto de exclamação (!) podem falhar. Se isso acontecer, renomeie o arquivo.

Dúvidas frequentes

O Windows mostrou um aviso de segurança. E agora?

É comum o Windows alertar sobre arquivos .bat baixados da internet. Se aparecer "O Windows protegeu seu computador", clique em Mais informações e depois em Executar assim mesmo. O arquivo é um texto simples: você pode abri-lo no Bloco de Notas para conferir o que ele faz antes de usá-lo.

O navegador bloqueou o download.

Alguns navegadores pedem confirmação para arquivos .bat. Escolha Manter ou Fazer download mesmo assim.

Meus arquivos não foram convertidos.

Confirme que o .bat está na mesma pasta dos arquivos HTML e que o Edge ou o Chrome está instalado. Páginas que carregam conteúdo da internet precisam de conexão ativa durante a conversão.

Meus arquivos são enviados para algum lugar?

Não. Toda a conversão acontece no seu computador, usando o navegador instalado nele.
